# PetBalance 구현 보고서

기준일: 2026-10-04  
대상: Notion 기능명세서 FR-01 ~ FR-28

## 구현 개요

PetBalance는 React + TypeScript + Vite 프런트엔드, FastAPI 분석 서버, SQLite 저장소, Electron 설치형 앱으로 구성되어 있다. 로그인한 사용자는 서버 저장소에 프로필과 급여 조합을 저장·복원할 수 있고, 설치형 앱에서는 로컬 SQLite를 사용한다.

## 주요 API

- `POST /api/auth/register`, `/login`, `/logout`: 계정과 세션 관리
- `GET /api/catalog/products`, `/standards`: 제품·영양 기준 조회
- `POST /api/session/analyze`: 현재 급여 조합의 영양 분석
- `POST /api/recommend`: 과잉·중복 위험을 재평가하는 추천
- `GET /api/prices/{product_id}`: 판매처별 가격과 최저가
- `POST /api/ocr/draft`, `/confirm`: 라벨 OCR 초안과 사용자 확인
- `POST /api/session/save`, `GET /api/session/restore/{pet_id}`: 프로필·급여 조합 저장과 복원

## 검증

- 백엔드: `python -m unittest discover -s tests -v`
- 프런트엔드: `cd frontend && npm run build`

## 다음 우선순위

1. 실제 급여 기록에 날짜·시간·메모를 추가하고 분석 이력 비교 화면 제공
2. 근거 출처와 적용 조건을 포함한 성분 상호작용 규칙 관리
3. 판매처 API 어댑터와 가격 갱신 실패·품절 상태 처리
4. 관리자용 제품·성분·기준 데이터 검수와 변경 이력 화면

> 현재 제품·영양 기준·가격 데이터는 기능 검증용 데모이며, 실제 급여 판단이나 수의학적 처방을 대신하지 않는다.
