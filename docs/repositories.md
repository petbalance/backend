# petbalance repositories

All repositories are private. Work is saved on `codex/petbalance-all-work`.

- https://github.com/petbalance/backend — application, Python and Spring backends, shelter, desktop, Android, documentation and deployment snapshots.
- https://github.com/petbalance/Frontend — frontend design work, diet comparisons and functional improvements.
- https://github.com/petbalance/.github — organization documentation and architecture.

Local credentials, databases, dependencies and generated builds are excluded by Git ignore rules. The frontend baseline ZIP is retained as a historical reference; current source uses petbalance branding.
